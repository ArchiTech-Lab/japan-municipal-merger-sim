# 市町村合併シミュレーション（全国1,762市区町村）

**デモ（単一HTML・外部通信ゼロ）→ https://architech-lab.github.io/japan-municipal-merger-sim/**

2050年の生産年齢人口と課税対象所得から作った合成変数 **X** が低い市町村から順に、
**隣接する市町村のうちXが最も低い方**と合併させ、全市町村のX ≥ Xmax になるまで
繰り返すとどうなるかを解いて、収斂過程をブラウザで再生できるようにしたもの。

X の作り方は4通り（A〜D）を切り替えられる。

| 案 | 考え方 |
|---|---|
| A | 人口と所得の弱い方（ボトルネック）で判定 |
| B | 人口と所得の幾何平均。一方が他方をある程度補える |
| C | 人口・所得を将来の住民税額（円）に換算して合算 |
| D | 人口規模のみ。他の案と比べる物差し |

## 画面でできること

- **A〜Dの切替**（案ごとにXmaxの決め方・統合回数が変わる）
- 合併後の市町村境・都道府県境の可視化（合併で一体化した範囲が単色の塊として見える）
- 都道府県別の「市町村の数」「生産年齢人口（2050年）」「面積」の棒グラフ（県の色で塗り、再生に合わせて変化）
- 陸で隣接しない離島の合併（海越しの点線で結んだ橋。下記「隣接の定義」参照）
- 拡大・縮小・移動、市町村名の表示、統合ログ
- 収斂過程の再生（速度調整・mp4/webm録画）

## ⚠ これは計画でも提案でもない

仮定を置いた機械的な計算であり、**政府・自治体の計画・意向とは一切関係がない。**
特定の市町村の存廃を主張するものではなく、「ある合成変数Xを全国一律に当てるとどうなるか」
だけを示している。モデルの限界は下記「わかっている限界」を参照。

## モデル

1. 対象年（2050年）の市町村別・生産年齢人口とGDP相当額を基に合成変数Xを作る
2. Xが最も低い市町村から処理を始める（合併の取り残しを防ぐ）
3. Xが閾値（Xmax）未満の市町村は、**隣接する市町村のうちXが最も低い方**と合併する
   （Xが高い方が吸収主体になり、県境も動く）
4. 全市町村のX ≥ Xmax で停止

### 隣接の定義

地理的な行政境界の隣接（国土数値情報N03のポリゴンがtouchesするか）を基本にする。
陸で隣接しない離島55市町村は、このままでは永久に合併相手がなく「到達不能」のまま残るため、
境界線どうしの最短距離を使った最小全域木で、陸の隣接だけでできる連結成分
（本州＋四国／九州／北海道／沖縄本島の4大陸塊＋離島の各成分）を最小本数の橋で全結合する。
ただし**4大陸塊どうしは直接橋を架けない**（史実に無い海峡横断合併を作らないため）。

### 人口統計が無い地点の扱い

- **北方領土**（色丹村・泊村・留夜別村・留別村・紗那村・蘂取村）と**無人島・埋立地・境界未定地**
  （鳥島・小笠原諸島の一部・名古屋港口埋立地等）は、日本の統計に存在しない、または実際に
  住民がいないため、**P=I=0（X=0）として通常どおり合併対象にする**
- **福島県の帰還困難区域13市町村**（いわき市・双葉町等）は、実際には相当数の住民がいるのに
  将来推計（IPSS）が個別に出ていないだけなので、0人扱いにはせず、**常にXmax達成扱いとして
  合併対象にしない**

## わかっている限界

- Xの作り方（案A〜D）もXmaxの具体的な値も、公式な行政基準ではなく本プロジェクトの概算モデル
- 隣接は地理的な行政境界の隣接であり、通勤圏・生活圏（RESAS等）は考慮していない
- 離島の橋は「最も近い場所」を機械的に選んでいるため、生活実態上の結びつき（航路・経済圏）とは
  異なる場合がある。奄美群島が沖縄側に付くなど、直感と異なる結果が出ることがある
- 案Dは実際の歳出データではなく、総務省の類似団体別職員数から作った概算モデル式に
  実データの人口を当てはめた概念実証
- 平成の大合併（1999〜2010年、市町村数3,232→1,727）との答え合わせは未実施
- 対象年は2050年のみ。2100年シナリオは未実装
